# 📊 Dashboard de Ventas — Northwind (Power BI)

Reporte interactivo desarrollado en Power BI Desktop sobre la base de datos de muestra **Northwind**, que simula las operaciones comerciales de una empresa distribuidora de alimentos. El análisis cubre ventas globales, distribución geográfica y desempeño por producto.

## 🎯 Objetivo

Explorar y visualizar el comportamiento de ventas de la empresa Northwind a través de un dashboard interactivo que permita analizar el rendimiento general, por país y por producto, facilitando la toma de decisiones basada en datos.

---

## 📐 Estructura del reporte

El reporte está organizado en **dos secciones principales** con filtros dinámicos:

### 🌍 Vista General / Por País
Permite alternar entre una visión global del negocio o filtrar la información por país específico.

### 📦 Vista General / Por Producto
Permite alternar entre el total de ventas o segmentar el análisis por producto individual.

---

## 📈 Visualizaciones incluidas

| Visual | Descripción |
|---|---|
| 💰 Total de ventas | KPI con el ingreso total generado |
| 🌐 Países y ciudades | Conteo de países y ciudades con presencia comercial |
| 🏆 Top productos | Ranking de los productos más vendidos |
| 📅 Ventas por año | Gráfica de tendencia de ventas a lo largo del tiempo |
| 🗺️ Mapa interactivo | Distribución geográfica de ventas por ciudad y país |
| 🥧 Distribución de ventas | Composición porcentual del total de ventas |

---

## 🗃️ Fuente de datos

**Northwind Database** — Base de datos de muestra desarrollada por Microsoft, que representa una empresa ficticia dedicada a la importación y exportación de alimentos especializados.

Incluye tablas de: clientes, pedidos, productos, empleados, proveedores y envíos.

---

## 🛠️ Herramientas utilizadas

- **Power BI Desktop** — Modelado de datos y construcción del dashboard
- **DAX** — Medidas y KPIs calculados
- **Power Query** — Transformación y limpieza de datos

---

## ▶️ Cómo abrir el proyecto

1. Descarga e instala [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (gratuito)
2. Clona o descarga este repositorio
3. Abre el archivo `Powr_BI_Northwind.pbix`
4. Explora los filtros de país y producto en el panel lateral
